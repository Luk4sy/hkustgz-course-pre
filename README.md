# hkustgz-course-pre · 港科广课程 Pre 助手

一个给 **Claude** 用的技能（Skill）。装上之后，Claude 会按一套固定、靠谱的流程，帮你准备港科广（HKUST(GZ)）课堂上的各种 pre：先讲懂内容，再一起规划怎么讲，最后做出能直接上台用的 PPT。

> English: A Claude skill for planning and building HKUST(GZ) course presentation slides (.pptx) with bilingual speaker notes, click animations and the school logo. Instructions below are in Chinese; the skill itself works in English too.

---

## 这是什么

你可以把它理解成一个"做 pre 的固定搭档"。

平时让 AI 做 PPT，常见问题是：它没搞懂内容就开始做，做出来一堆字，讲的时候也不知道说什么。这个技能把顺序定死了：

1. **先讲懂**：用大白话把论文、项目或者案例给你讲清楚。
2. **再规划**：和你一起定每一页讲什么、配什么图、花多少秒。
3. **你说"开动"才开始做**：在这之前它不会动手做 PPT。

## 能做哪些汇报

| 类型 | 举例 |
|---|---|
| 论文 pre | 按 Author（作者）/ Reviewer（审稿人）/ Researcher（研究者）角色讲一篇论文 |
| 课程项目汇报 | 中期进度汇报、期末成果展示 |
| 开题 / 研究提案 | 讲清楚想研究什么、为什么、怎么做、多久做完 |
| 小组展示 | 多人分工，自动安排谁讲哪几页、怎么交接 |
| 话题 / 案例分析 | 任何专业都能用的通用思路，不需要专业背景 |
| 技术演示 | 展示一个系统或作品，带视频或现场演示 |
| 短 pitch | 1–3 分钟的快速介绍 |

## 怎么安装

**在 Claude 网页版 / 桌面版里：**

1. 在这个页面点绿色的 **Code → Download ZIP**，下载后解压。
2. 找到文件夹 `skills/hkustgz-course-pre`，把它单独压缩成一个 zip（Mac：右键 → 压缩；Windows：右键 → 发送到 → 压缩文件夹）。
3. 打开 Claude 的设置，找到 **Skills（技能）**，上传这个 zip，并打开开关。

**在 Claude Code 里：** 把 `skills/hkustgz-course-pre` 文件夹复制到 `~/.claude/skills/` 下面即可。

## 怎么开始

装好以后，直接跟 Claude 说就行，比如：

- "帮我准备一个港科广课程 pre，8 分钟，我是 Reviewer 角色，论文在附件里。"
- "我们小组下周要做期末项目展示，5 个人，每人 3 分钟。"
- "帮我做一个关于上海垃圾分类政策的案例分析 pre。"

把作业要求、老师的特别要求（比如开头必须讲哪几项）、相关材料一起发给它，效果最好。

## 整个过程

1. **说清楚需求**：Claude 会问你缺的信息，比如几分钟、什么角色、PPT 用中文还是英文、喜欢什么颜色。
2. **讲懂内容**：它先用简单的话给你讲，你觉得没听懂就直接说，它会再讲得更简单。
3. **规划大纲**：每页讲什么、放什么图、多少秒，你满意了再往下走。
4. **说"开动"**：它开始做 PPT。
5. **检查**：它会自己检查有没有文字溢出、时间是否超时、动画和逐字稿是否对得上。
6. **交付**：你拿到一个 .pptx 文件。

## 你需要准备什么

- 作业要求（时长、角色、老师的特别要求）
- 材料：论文 PDF、项目报告、数据、图片等
- 如果想在 PPT 里放视频：**请自己录屏**后发给它（它不会帮你从 YouTube 等网站下载视频）
- 如果想放学校 logo：发一张白底的 logo 图片（本仓库不附带 logo 文件）

## 你会得到什么

- 一份 **.pptx** 文件，WPS 和 PowerPoint 都能打开
- 每页的**备注里有中英双语逐字稿**，演讲者模式下只有你自己看得到
- 逐字稿里标好了 **[CLICK] / 【点击】**，告诉你什么时候该点下一步
- 内容按点击一步步出现的**动画**
- 每页右上角的**学校 logo**，背景深浅会自动换成彩色或白色版本
- 如果有视频，进入那一页会**自动静音循环播放**

## 常用说法

| 你说 | 它会做 |
|---|---|
| "还是没讲清楚" | 换更简单的说法再讲一遍 |
| "开动" | 开始做 PPT |
| "把逐字稿发给我就行" | 只发文字，不改文件 |
| "幽默一点" / "严肃一点" | 调整逐字稿语气 |
| "换个颜色" | 推荐几种配色让你选 |
| "这两个 pre 是同一天的" | 两份逐字稿互相呼应，用"刚才"而不是"上次" |

## 需要注意的地方

- **内容要自己核对**：AI 可能讲错细节，上台前请对照原文检查一遍关键数字。
- **视频自动播放**：PowerPoint 支持得比较好；WPS 不一定，上台前请先试一下。
- **学校 logo** 属于学校，本仓库不提供，请自己准备。
- 这是学生自发做的工具，**和港科广官方无关**。

## 常见问题

**WPS 怎么打开演讲者模式？**
放映 → 设置放映方式 → 勾选"显示演讲者视图"，然后从头放映。

**不是港科广的学生能用吗？**
能。把 logo 换成你自己学校的就行，其他流程都是通用的。

**一定要用英文 PPT 吗？**
不用。开始时告诉它你要中文还是英文就行。

## 仓库结构（给想改代码的人）

```
skills/hkustgz-course-pre/
├── SKILL.md            # 技能本体：流程 + 各类 pre 的讲法模板
└── scripts/
    ├── animate.py      # 点击动画、翻页淡入、视频自动循环
    ├── fixnotes.py     # 备注逐行分段（解决 WPS 里挤成一段）
    ├── logo_cutout.py  # 把白底 logo 抠成透明 + 白色两个版本
    └── add_logo.py     # 每页右上角加 logo，按背景深浅自动选版本
```

脚本依赖：Python 3、`python-pptx`、`Pillow`、`numpy`；`add_logo.py` 还需要 LibreOffice 和 poppler（`pdftoppm`）。
